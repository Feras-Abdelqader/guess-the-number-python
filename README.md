# 🎮 Guess The Correct Number

My first Python project!

A simple number guessing game where the player tries to guess a secret number generated randomly by the computer.

## Features
- Random number generation.
- 5 attempts per game.
- HIGH and LOW hints.
- Input validation.
- Win and lose messages.

## How to Play
1. Run `GuessTheNumber.py`.
2. Pick a number between 1 and 10.
3. Follow the HIGH and LOW hints.
4. Guess correctly within 5 attempts to win!

## Technologies
- Python 3
